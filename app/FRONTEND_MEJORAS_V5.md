# Al Rescate — mejoras frontend V5

## Carrito y confirmación de pedido
- Encabezado renovado con contexto de compra y pasos visuales.
- Identificación más clara del comercio del que procede el pedido.
- Líneas de producto con controles de cantidad accesibles y acción para quitar un producto.
- Resumen de subtotal, tarifa de envío y total con jerarquía visual mejorada.
- Mensaje de pago en efectivo y recordatorio de revisar los datos de entrega.
- Conserva las mutaciones, cotización del envío, direcciones guardadas, geolocalización y flujo actual de creación de pedidos.

## Validación
No se ejecutó compilación ni pruebas automatizadas en este entorno. Ejecutar `npm ci`, `npm run check` y `npm run build` desde `app/` antes de desplegar.
