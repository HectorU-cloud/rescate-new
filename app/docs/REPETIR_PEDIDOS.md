# Repetir pedidos

En el detalle de un pedido a domicilio entregado, el cliente puede usar **Repetir pedido**.

Antes de llenar el carrito, la aplicación vuelve a consultar el catálogo actual del comercio y comprueba que el local esté abierto. Solo agrega productos que continúan disponibles; los que fueron eliminados o agotados se omiten. El carrito conserva los precios actuales del catálogo, no los precios históricos del pedido anterior. Al terminar, el cliente pasa al carrito y debe revisar dirección, cobertura, mínimo y tarifa antes de confirmar.

Los pedidos de rescate para retirar en el local no muestran esta acción porque su disponibilidad depende de packs y cantidades que pueden haber cambiado.

Las notificaciones push quedan fuera de este cambio y pueden configurarse en una etapa posterior.
